# Bug Fix Report — 2026-08-16

## 🔴 BUG 1 (CRITICAL): Wrong Gemini Model Names
**File:** `app/services/ai_engine.py` — Line 19

**Problem:** `gemini-3.5-flash`, `gemini-3.6-flash`, `gemini-3.5-flash-lite` என்ற models
Google-இல் exist-ஆகவே இல்லை. Comment-ல் `gemini-2.5-flash` சரியா இருந்தது,
code-ல் மட்டும் `3.x` version-ஆக type ஆயிருந்தது.
AI calls முழுவதும் fail ஆகும், rule-engine fallback மட்டுமே காட்டும்.

**Fix:**
```python
# Before
GEMINI_MODELS = ["gemini-3.5-flash", "gemini-3.6-flash", "gemini-3.5-flash-lite"]

# After
GEMINI_MODELS = ["gemini-2.5-flash", "gemini-2.5-flash-lite", "gemini-2.0-flash"]
```

## 🟡 BUG 3 (MEDIUM): IST Timezone Missing in Time Filters
**Files:**
- `app/api/routes/strategy.py` — `_time_filter()` Line 107
- `app/services/market_regime.py` — `_time_session()` Line 52

**Problem:** `datetime.now()` server-local time use பண்றது. Render server UTC-ல்
run ஆகும். IST = UTC+5:30 இருப்பதால் 9:15 IST = 3:45 UTC — session checks
5h30m wrong-ஆக இருந்தன. "CLOSED" / "OPENING" / "MID" labels தவறா காட்டும்.

**Fix:**
```python
# Added to both files:
from zoneinfo import ZoneInfo
_IST = ZoneInfo("Asia/Kolkata")

# _time_filter():  datetime.now() → datetime.now(_IST)
# _time_session(): datetime.now().time() → datetime.now(_IST).time()
```

## 🟡 BUG 4 (MEDIUM): Trading Capital Hardcoded
**Files:**
- `app/api/routes/strategy.py` — Line 597
- `app/config.py` (new field added)
- `.env.example` (new entry added)

**Problem:** Risk engine-க்கு `capital = 200000` hardcode ஆயிருந்தது.
Comment-லயே "settings-இல் இருக்கணும்" சொல்லியிருந்தது, implement ஆகல.

**Fix:**
```python
# app/config.py — new field:
default_capital: int = Field(200000, alias="DEFAULT_CAPITAL")

# app/api/routes/strategy.py:
capital = settings.default_capital,  # was: 200000
```
`.env` / `.env.example`-ல் `DEFAULT_CAPITAL=500000` (உங்கள் actual capital) set பண்ணலாம்.
